# ATS_CV

This repository allows me to create a PDF in which my CV is generated with the ATS format.

## Current form features

- Bootstrap 5 responsive HTML form (`index.html`) for capturing CV profile information.
- Main action button labeled **Exportar a PDF**.
- Language selector next to the export button with options:
  - Español
  - Inglés
- Additional short input under the first **Experiencia profesional** section to capture:
  - Nombre del cargo
  - Año de inicio
  - Año de finalización
